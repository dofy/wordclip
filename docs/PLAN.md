# WordClip 开发计划

> 多平台(macOS / iOS / iPadOS)单词收集与间隔重复学习工具。
> 当前目标学习语言:英语;架构目标:可扩展到任意语言。
>
> 实际实现进度见 [PROGRESS.md](PROGRESS.md),架构决策见 [ARCHITECTURE.md](ARCHITECTURE.md)。

---

## 1. 产品目标

随时随地把遇到的单词「剪藏」进个人词典,离线查询释义读音,通过间隔重复评定熟悉度并推送复习,数据可在多端同步。

**核心价值**:收集要快(不打断阅读)、查词要全离线、复习要科学(间隔重复)、界面要本地化。

> **两类「语言」务必分清**(详见架构文档):
> - **学习内容语言** —— 你在学的语言(英语 / 日语…),由 `LanguagePack` 决定。
> - **界面语言** —— App 菜单按钮的显示语言,跟随系统,用 `.xcstrings` 本地化。
>
> 二者独立:中文界面可学英语,也可学日语。

## 2. 项目约束

- ✅ **分发路线(见下方「分发路线」)**:iOS 上 App Store;macOS 走 Developer ID + 公证 + 网站分发(**不上 MAS**,以保留原生全局取词)。macOS 因此无需为沙盒/审核避开 Accessibility 直读。
- ⚠️ **暂无 Apple 付费开发者账号的完整配置** → iCloud/CloudKit 同步暂缓(当前仅预留 UI);当前用本地 SwiftData(模拟器即可跑通收集/查词/复习),账号到位后主要改 `ModelConfiguration` 即可切云。内购代码已实装(见 §5),待 ASC 商品配置 + 真机/沙盒购买验证。
- ✅ **优先级**:先打磨「收集 + 离线查词」,复习其次,同步最后。
- ✅ **界面多语言(中/英)从一开始就纳入**:所有用户可见文案走 String Catalog,禁止硬编码。
- ✅ **只导入用户有权使用的词典**:App 不打包/分发任何第三方商业词典。

## 3. 技术选型

| 方面 | 选择 | 理由 |
|------|------|------|
| UI | SwiftUI(多平台单一代码库) | 一套代码覆盖 Mac/iOS/iPad |
| 数据/同步 | SwiftData(+ 未来 CloudKit) | iCloud 私有库自动同步,免自建后端 |
| 共享核心 | Swift Package `WordClipKit` | 模型/算法/词库逻辑与 UI 解耦,便于测试与复用 |
| 词库 | 开源离线词库(英语 ECDICT)→ SQLite(GRDB) | 可控、离线;数据授权见 [DICTIONARY-LICENSING.md](DICTIONARY-LICENSING.md)(收费须知:非"版权干净",MIT 仅覆盖代码) |
| 读音 | `AVSpeechSynthesizer` | 系统自带、离线、多语言 |
| 全局快捷键 | macOS 原生(`KeyboardShortcuts` + Accessibility 直读) | 跨平台框架不可行;直读不改剪贴板 |
| 复习算法 | SM-2 起步,封装为协议,可换 FSRS | 成熟、易实现、可升级 |

> ⚠️ **系统内置词典(牛津等)不作为数据源**:iOS 无法读取文本,macOS 为半公开 API 且内容版权受限。仅作为「跳转到系统查词」的便捷入口。详见架构文档 §5。

## 4. 功能范围

### 已完成方向

- 收集:macOS 全局收词(Accessibility 直读 + HUD 反馈)、URL Scheme、状态栏常驻、手动/粘贴添加。
- 离线查词:内置 ECDICT 5 万词 + 词形还原 + 自定义词典导入(CSV / SQLite)叠加 + 释义结构化。
- 生词本:三栏布局、搜索(含词典未收录词一键收录)、排序、收藏、朗读、修复、全套快捷键。
- 复习:SM-2 翻卡、认识/不认识评分、本地通知提醒、统计面板。
- 数据:JSON 备份导入/导出(智能合并)。
- 基建:中/英界面本地化、`WordClipKit` 单测、CI。

> 明细见 [PROGRESS.md](PROGRESS.md)。

### 计划中方向

- **付费墙骨架(mock,不需账号)**:Paywall UI(单档「终身买断」)、`isPro` 功能闸门、免费上限逻辑。
- **iCloud 同步(先预留 UI,功能待账号)**:设置页放置同步开关/状态占位 UI;真实同步待 CloudKit 私有库 + Apple 付费账号,主要改 `ModelConfiguration`。
- **内购上线验证(待账号)**:`StoreKitEntitlement` 已实装并在 Release 生效(见 §5);待 App Store Connect 配置商品 + 真机/沙盒购买与恢复验证。不做订阅,仅一次性买断。
- **在线词典服务(Pro)**:通过在线服务直接检索并导入扩展词典,而非仅导入本地准备好的文件。需先明确后端/词源(合规:只提供用户有权使用的词库,App 不分发第三方商业词典);现有本地 CSV / SQLite 导入作为兜底保留。
- **收集增强**:iOS Share Extension(系统分享菜单收词)。
- **复习增强**:更多测试模式(中→英拼写、听音辨义)。
- **AI 接口**:释义增强 / 例句 / 词根讲解(`AIProvider` 协议已预留,默认关闭)。
- **多语言学习内容**:将英语逻辑收敛进 `LanguagePack`,用日语跑通最小验证,通过 build configuration 产出语言变体。

## 分发路线(2026-07-09 定稿)

**macOS 走 Developer ID + 公证 + 网站分发,不上 Mac App Store;iOS 正常上 App Store。**

- **根因**:全局选中取词依赖 Accessibility 跨 App 直读文本,而 App Sandbox(MAS 强制)禁止一切跨 App 文本读取。取词与 MAS 二者不可兼得,**优先保取词体验**。详见架构文档 §3.1。
- **曾尝试并否决**:`feat/mas-sandbox-capture` 分支试过「沙盒 + 快捷指令 / App Intents 收词」换 MAS 资格,但需用户手工配快捷指令、丧失开箱即用的全局取词,体验不可接受,已放弃该分支。
- **付费实现分平台**:iOS 用 StoreKit(App Store 内购,Small Business 15%,见 §5);**macOS 网站分发的收费需 Merchant of Record(如 Lemon Squeezy)+ 离线许可校验**,§5 的「15% 抽成」仅适用 iOS/App Store 侧。
- **回退锚点**:`v0.2.0` tag(原生 AX 取词 + 网站分发基线)。

## 5. 收费政策(已定)

**模式**:Freemium —— 核心「收集 + 基础查词」永久免费,进阶能力做成 **WordClip Pro**。技术方案见架构文档 §3.8 / §4.5(StoreKit 2 + CloudKit,零后端)。

### 定价:一次性买断 · 终身制

- **只有一档:一次性购买,终身解锁 Pro**。**不做月订阅 / 年订阅**。
- 一次付费永久拥有 Pro 全部权益及后续更新。
- 申请 Small Business Program → 抽成 15%。具体价格待市场/竞品调研后定。

### WordClip Pro 权益

1. **OCR 收词**(已实现,macOS)—— 框选屏幕任意区域,Vision 识别其中单词并收录。适用于图片 / PDF / 不可选文本。
2. **iCloud 同步** —— 词典与单词数据跨设备自动同步(CloudKit 私有库)。当前无付费账号,**先预留 UI**(见架构文档 §4)。
3. **导入 / 导出** —— 个人词库 JSON 备份的导入 + 导出(免费仅导出)。
4. **词典功能(在线词典服务)** —— 通过在线服务直接检索/导入扩展词典,而非仅导入本地准备好的文件(计划中,见架构文档 §3.3)。

### 免费 vs Pro 功能边界

| 功能 | 免费 | Pro |
|------|:---:|:---:|
| 收词(选中 / URL Scheme / 分享菜单) | ✅ | ✅ |
| 基础离线查词(内置词库:音标 + 释义 + TTS) | ✅ | ✅ |
| 个人词典管理、打标签 | ✅ | ✅ |
| 间隔重复复习 | ✅ | ✅ |
| 学习统计 / 复习提醒 | ✅ | ✅ |
| **OCR 收词**(框选屏幕识别单词) | ❌ | ✅ |
| **iCloud 多设备同步** | ❌ | ✅ |
| **导入 / 导出**(个人词库备份) | 仅导出 | 导入 + 导出 |
| **词典功能(在线词典服务、扩展词库)** | ❌ | ✅ |
| AI 释义 / 例句 / 讲解(未来) | ❌ | ✅ |
| 多语言学习包(未来) | 单语言 | 全部 |

> 原则:**收集与基础查词永久免费**(先养成习惯、做口碑),把「同步 / 在线词典 / 进阶」作为付费点。免费上限阈值(若设)上架前再调。
