# WordClip 开发计划

> 多平台（macOS / iOS / iPadOS）单词收集与间隔重复学习工具。
> 当前目标语言：英语；架构目标：可扩展到任意语言。

---

## 1. 产品目标

随时随地把遇到的单词「剪藏」进个人词典，离线查询释义读音，通过测试评定熟悉度并按间隔重复推送复习，数据 iCloud 多端同步。

### 必须有（MVP）

1. 桌面端全局快捷键，捕获当前选中文本中的单词并收录
2. 本地离线词库：音标 + 释义；系统 TTS 读音
3. 个人词典的增删改查、打标签、查看收集来源
4. 间隔重复测试，按结果给出 5 级熟悉度
5. iCloud 自动同步
6. 手动导入 / 导出（CSV、JSON）

### 应该有

7. iOS/iPad 通过分享菜单收集
8. 复习提醒（本地通知）
9. 学习统计（今日新词、待复习、掌握率）
10. **界面多语言（i18n）**：App 界面支持中文 / 英文（用 String Catalog），界面语言与学习语言相互独立

> **两类「语言」务必分清**（详见架构文档）：
> - **学习内容语言** —— 你在学的语言（英语 / 日语…），由 `LanguagePack` 决定
> - **界面语言** —— App 菜单按钮的显示语言，跟随系统，用 `.xcstrings` 本地化
> 二者独立：中文界面可学英语，也可学日语。

### 未来（预留接口，先不实现）

11. AI 释义 / 例句 / 词根讲解（`AIProvider` 协议）
12. 多语言版本（日语等）通过语言包 + 构建变体产出
13. Web 端（仅在核心逻辑沉淀为可移植包后再评估）

## 1.5 已确认的项目约束

- ✅ **计划上架 App Store** → 全局快捷键等必须避开私有 API，走合规方案（Services 菜单为基线）。
- ⚠️ **暂无 Apple 付费开发者账号** → iCloud/CloudKit 同步与真机调试需付费账号，**因此同步功能推迟**：

  - 账号到位后再开启 CloudKit —— SwiftData 从本地切云端基本只改 `ModelConfiguration`，无需重写数据层。
- ✅ **优先级：先打磨「收集 + 离线查词」**，复习测试其次，同步最后。
- ✅ **界面多语言（中/英）从一开始就纳入**：所有用户可见文案走 String Catalog，禁止硬编码。
- ✅ 项目名保留 `WordClip`。

## 2. 技术选型结论

| 方面 | 选择 | 理由 |
|------|------|------|
| UI | SwiftUI（多平台单一代码库） | 一套代码覆盖 Mac/iOS/iPad |
| 数据/同步 | SwiftData + CloudKit | iCloud 私有库自动同步，免自建后端 |
| 共享核心 | Swift Package `WordClipKit` | 模型/算法/词库逻辑与 UI 解耦，便于测试与未来复用 |
| 词库 | 开源离线词库（英语 ECDICT）→ SQLite | 版权干净、可控、离线 |
| 读音 | `AVSpeechSynthesizer` | 系统自带、离线、多语言 |
| 全局快捷键 | macOS 原生（见架构文档方案对比） | Web/跨平台框架不可行 |
| 复习算法 | SM-2 起步，封装为协议，可换 FSRS | 成熟、易实现、可升级 |

> ⚠️ **系统内置词典（牛津等）不作为数据源**：iOS 无法读取文本，macOS 为半公开 API 且内容版权受限。仅作为「跳转到系统查词」的便捷入口。详见架构文档。

## 3. 里程碑与任务拆解

> 顺序已按确认的优先级调整：**收集 + 离线查词优先**，复习其次，**iCloud 同步推迟到账号就绪后**。

### M0 · 项目骨架 + i18n 基建（第 1 周）

- [ ] 创建 Xcode 多平台工程 `WordClip`（App target：macOS + iOS）
- [ ] 抽出 `WordClipKit` Swift Package（models / services / engine）
- [ ] 接入 SwiftData，定义模型（见架构文档）—— **先纯本地，CloudKit 配置留好开关但不启用**
- [ ] **建立 String Catalog（`.xcstrings`），配置中文 + 英文，约定全部文案走 `String(localized:)`**
- [ ] CI：GitHub Actions 跑 `swift test`（对 Kit 做单元测试）
- [ ] 基础导航骨架（词典列表 / 详情 / 测试 / 设置）

**验收**：空壳应用在模拟器运行，切换系统语言界面随之中/英切换，Kit 单测通过。

### M1 · 离线词库 + 查词（第 2 周）—— 优先级最高

- [ ] `data/` 下编写脚本：下载 ECDICT → 生成精简 SQLite（lemma、IPA、释义、词频）
- [ ] `DictionaryProvider` 协议 + SQLite 实现（GRDB）
- [ ] 词库随包分发（首启动拷贝到 App Support）
- [ ] 查词 UI：输入/选中即查，展示音标 + 释义 + TTS 朗读按钮

**验收**：离线输入任意常见英文词，秒级返回释义与发音。

### M2 · 收集流程（第 3–4 周）—— 优先级最高

- [ ] **macOS 全局快捷键 / Services 菜单**：触发 → 读取选中文本 → 弹出快速收录面板 → 写本地库
  - Services 菜单为合规基线；全局热键+模拟复制作为增强选项（需 Accessibility 权限引导）
- [ ] 收集时自动查词，记录来源 App / 时间 / 原句（若可得）
- [ ] **iOS Share Extension**：从任意 App 选中文本分享进来收录
- [ ] 词条去重与合并策略

**验收**：在浏览器/阅读器选中单词，一键进本地库并自动带出释义。

### M3 · 复习与测试（第 5–6 周）

- [ ] `ReviewEngine` 协议 + SM-2 实现（间隔、熟悉度 0–4/5 级）
- [ ] 测试模式：英→中选择、中→英拼写、听音辨义
- [ ] 复习队列：到期词排程
- [ ] 本地通知提醒
- [ ] 统计面板

**验收**：完成一轮测试后，词条熟悉度与下次复习时间正确更新。

### M4 · 导入导出 + 打磨（第 7 周）

- [ ] CSV / JSON 导入导出（含字段映射、去重）
- [ ] 设置页、外观、空状态、错误处理
- [ ] 界面多语言全面校对（中/英文案审查）
- [ ] 图标与基础品牌

**验收**：导出再导入数据无损；中英界面文案完整无硬编码遗漏。

### M5 · iCloud 同步（待开发者账号就绪后）

- [ ] 申请并配置 Apple 付费开发者账号、CloudKit 容器
- [ ] 开启 SwiftData CloudKit 集成（改 `ModelConfiguration`）
- [ ] 多设备同步联调、冲突处理（复习进度取更靠前者）
- [ ] 真机调试

**验收**：两台设备数据同步一致。

### M6 · 多语言学习内容可扩展性（验证性）

- [ ] 将英语相关逻辑收敛进 `LanguagePack`（分词、词库 Provider、TTS 语言、复习参数）
- [ ] 用日语跑通最小验证（`NaturalLanguage` 分词 + JMdict 子集）
- [ ] 通过 build configuration 切换语言变体，产出第二个 scheme

**验收**：切换 scheme 能 build 出「日语版」最小可用形态。

### 预留 · AI 接口

- [ ] 定义 `AIProvider` 协议（释义增强 / 例句 / 讲解）
- [ ] 提供一个 mock 实现占位，UI 留入口但默认关闭
