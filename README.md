# WordClip

随时随地收集单词、离线查词、间隔重复复习的多平台单词学习工具。当前面向英语,架构上支持扩展到任意语言。

**平台**:macOS · iOS · iPadOS
**技术栈**:SwiftUI(多平台单一代码库)· SwiftData · Swift Package(`WordClipKit` 共享核心)· GRDB(离线词库)

---

## 已实现功能

### 收集
- **macOS 全局收词**:任意 App 中选中单词,按快捷键(默认 `⌥⌘C`)一键收录,屏幕弹出 HUD 提示,不打断当前 App。基于 Accessibility 直读选中文本,不改动剪贴板。
- **OCR 收词(Pro)**:按快捷键(默认 `⌥⌘O`)框选屏幕区域,Vision 识别其中单词,经内置词典校验后弹选词面板多选收录。适用于图片 / PDF / 不可选文本。
- **状态栏图标**:快速启用/停用收词、打开主窗口/设置、开始复习、查看今日概览。
- **URL Scheme**:`wordclip://collect?word=<单词>`,可从快捷指令、脚本、其他 App 调用收词。
- **iOS / iPadOS**:手动输入或从剪贴板粘贴添加单词。

### 词典与查词
- **内置离线词库**:ECDICT 精简版约 5 万词(音标 + 中英释义),GRDB SQLite,随包分发。
- **词形还原**:`brought → bring` 等变形自动归一到原型查词。
- **自定义词典导入**:支持 CSV 和 ECDICT 结构的 SQLite,多本词典按优先级叠加查询,可单独启用/停用/删除/排序。
- **释义结构化**:按词性分行、学科标记(`[计]`/`[化]`)灰字、中英释义分区展示。

### 生词本
- **三栏布局**(macOS / iPad):导航 → 列表 → 详情。
- **搜索**:生词本匹配词优先,下方列出词典中未收录的匹配词,点击预览并一键收录。
- **排序**:按收录时间 / 字母 / 熟悉度,记忆上次选择。
- 收藏、TTS 朗读、释义修复、删除。
- **全套键盘快捷键**(macOS / 接键盘的 iPad):导航切换、搜索定位、增删、朗读、收藏等。

### 复习
- **SM-2 间隔重复算法**:翻卡看释义,标记"认识/不认识"——答对拉长下次间隔、答错重置回明天,自动排程复习。
- 翻面不可逆(防误触),学习时 `空格` 翻面、`←/→` 评分。
- 生词本徽标区分"新词 / 待复习"。
- **本地通知**每日复习提醒。

### 统计与数据
- 统计面板:总词数、待复习、新词、掌握率。
- **JSON 备份导入/导出**:按单词智能合并,不覆盖已有学习进度。

### 付费(骨架)
- **WordClip Pro 付费墙**:单档「终身买断」页面(权益:OCR 收词、iCloud 同步、导入/导出)。
- **功能闸门**:免费/Pro 边界统一走 `entitlement.isPro`;当前用 `MockEntitlement`,可在设置「模拟 Pro」调试。
- **StoreKit 2 骨架**:`StoreKitEntitlement`(一次性内购)+ 本地 `.storekit` 配置,Xcode Run 即可测购买流程,无需付费账号。
- **免费**:收集 + 基础离线查词 + 生词本 + 复习 + 统计 + 导出。**Pro**:iCloud 同步、导入。

### 其他
- **界面多语言**:中文 / 英文(String Catalog),界面语言与学习语言相互独立。
- **iCloud 同步预留 UI**:设置页占位开关(真实同步待 Apple 付费开发者账号)。
- `WordClipKit` 单元测试 44 条覆盖算法 / 词库 / 导入 / 统计 / 权益。

## 计划中功能

> **收费政策(已定)**:一次性购买 · 终身买断(不做订阅)。**WordClip Pro** 权益:OCR 收词、iCloud 同步、导入/导出(及未来在线词典)。收集与基础查词永久免费。详见 [PLAN.md](docs/PLAN.md#5-收费政策已定)。

- **付费墙(Pro)**:Paywall UI(单档终身买断)+ `isPro` 功能闸门(权益抽象层 `EntitlementProvider` / `MockEntitlement` 骨架已就位)。
- **iCloud 同步**:SwiftData + CloudKit 多设备自动同步(先预留设置页 UI,真实同步待 Apple 付费开发者账号)。
- **真实内购**:StoreKit 2 一次性内购,替换 mock 权益实现。
- **在线词典服务**:通过在线服务直接检索/导入扩展词典(不止导入本地文件);本地 CSV / SQLite 导入作为兜底保留。
- **iOS Share Extension**:从系统分享菜单收词。
- **更多复习模式**:中→英拼写、听音辨义等(当前为翻卡认识/不认识)。
- **AI 增强**:释义 / 例句 / 词根讲解(`AIProvider` 协议已预留,当前为占位实现)。
- **多语言学习内容**:日语等(当前收词逻辑面向英语)。

- macOS + **完整版 Xcode**(仅装 Command Line Tools 无法构建 App)
- `brew install xcodegen`;`*.xcodeproj` 不入库,克隆后运行 `xcodegen generate` 生成工程
